## ✨ About

I'm **Mickey Jr**, aka **Coderastrophy** — a full-stack developer based in Addis Ababa, Ethiopia, and a 3rd-year Computer Science and Engineering student at Adama Science and Technology University (ASTU).

This portfolio is my personal corner of the web — part project showcase, part blog, built with curiosity, precision, and a philosophical edge. I approach code the way I approach film, music, and ideas: studying structure and depth rather than skimming the surface.

> *"We are not the reason for the existence of the universe, but our ability for self-awareness and reflection makes us special within it."* — Mickey Jr

## 🏗️ Running Locally

```bash
# Clone the repo
git clone https://github.com/Coderastrophy/<repo-name>.git

# Move into the project
cd <repo-name>

# Install dependencies
npm install

# Run the dev server
npm run dev
```
